# زاد المسلم (Zad al-Muslim)

تطبيق ويب تقدّمي (PWA) إسلامي: قرآن كريم، مواقيت صلاة، أذكار، تسبيح، قبلة، ودردشة خاصة برموز دعوة.

**حالة النسخة:** مصدر معاينة v161 ‏(APP_VER=140) بتاريخ 1 تشرين الثاني 2026 — **ليس جاهزاً للإنتاج النهائي**؛ مرحلة مطابقة التصميم التالية (v162) قيد العمل وستُرفع لاحقاً.

## المحتوى
- `public/` — التطبيق الكامل (واجهة، خدمة العمل دون اتصال، بيانات القرآن والأذكار، جدول ديانات الرسمية لقونيا/كاراتاي لشهر تشرين الثاني 2026)
- `firebase.json` — إعدادات الاستضافة
- `firestore-v4.rules` — قواعد قاعدة البيانات (دردشة برموز دعوة فقط)

## التشغيل
مشروع Firebase Hosting + Firestore. عدّل إعدادات المشروع في `public/index.html` و`public/chat.js` ثم:
```
firebase deploy --project <your-project>
```
